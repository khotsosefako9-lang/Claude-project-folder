# Offer: Website Fix Sprint for small businesses

**Status:** primary offer, price hypothesis, not yet tested with a buyer (2026-10-27).

## Who it's for
Owner-run local businesses (trades, retail, food, services) whose public website has a
problem a customer would actually hit: the site is down, service pages return "page not
found", the layout breaks on phones, or the homepage is so heavy it loads slowly.

## Why it's credible
Every pitch starts with a free one-page check of *their own* site, with each finding
confirmed by hand (two real examples are kept privately; see PROJECT.md). The buyer sees the problem before paying,
and every fix can be verified afterward by the same check.

This is a deliberate trust lever for a new provider with no reviews; revisit after 3 paid jobs.

### Optional add-ons inside a Fix Sprint (AI search readiness, no ranking promises)
- **LocalBusiness structured data**: name, address, phone, hours and service area as schema.org JSON-LD, so search engines and
  AI assistants read the basics reliably. 67% of the 293 small-business sites checked on 2026-10-28 had none.
  Google says this is optional for AI Overviews, so it's offered as tidy-up, not as a visibility guarantee.
- **AI crawler access check**: confirm robots.txt doesn't block the search/answer crawlers (OAI-SearchBot, ChatGPT-User,
  Claude-SearchBot, PerplexityBot, Bingbot, Googlebot). Rare (7 of 293), but serious when it happens, e.g. an expired
  Squarespace site serving `Disallow: /` to everyone.

## Inclusions / exclusions
- Included: the fixes listed in the written check that the client approves, one round of revisions, a short before/after summary.
- Not included: redesigns, new pages or copywriting beyond small text fixes, hosting/domain purchases,
  ongoing maintenance, SEO ranking promises, legal accessibility compliance guarantees,
  e-commerce or payment-system changes. Anything else is quoted separately before work starts.

## Access (no password sharing)
- WordPress site down: client forwards the WordPress **Recovery Mode** email link (time-limited), or creates a temporary admin user that they delete afterwards.
- WordPress site up: temporary admin user, deleted by the client at handover.
- Wix / Squarespace / Duda / GoDaddy builders: contributor invite if the platform allows it; otherwise exact step-by-step fix instructions with screenshots.

## Acceptance criteria
Each approved issue re-checked with the same automated scan plus a manual phone-screen check:
broken links return 200 or 301, no horizontal scroll at 390px width, compressed images under 300 KB,
site loads without errors. The client confirms in writing (email reply is fine).

## Honesty notes for all sales copy

- Checks are labelled "independent, unsolicited check of public pages".
